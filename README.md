# KitchenFlow

Система управления процессами ресторана: от прихода продуктов и складского учёта
до закупок, смен, сотрудников и управленческих показателей. Самостоятельный
AI-assisted проект полного цикла.

## Возможности

- склад, остатки, приходы и списания;
- закупки, поставщики, накладные и оплаты;
- технологические карты блюд;
- закрытие смен и учёт продаж;
- сотрудники, события и ролевой доступ;
- отчёты и операционная панель;
- публичный сайт с интерактивной демонстрацией;
- тесты, контейнеризация и инфраструктурные конфигурации.

## Архитектура и технологии

- Bun workspaces;
- React, TypeScript и Vite для рабочего интерфейса;
- Astro для публичного сайта;
- Hono, Prisma и PostgreSQL для серверной части;
- Zod и общий пакет контрактов;
- Tailwind CSS;
- Playwright и автоматизированные тесты;
- Docker и Terraform.

## Демо

https://kitchenflow-nine.vercel.app/

Демонстрационные данные работают только в текущей вкладке и не являются реальными
данными ресторана.

## Запуск

Требуется Bun версии, указанной в корневом `package.json`.

```bash
bun install
bun run dev
```

Для серверной части необходимо отдельно настроить локальные переменные окружения по
файлам `.env.example`. Реальные секреты в репозитории отсутствуют.
